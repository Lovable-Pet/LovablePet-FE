## ✨ LovablePet

LovablePet은 유기동물과 입양자의 라이프스타일 적합도를 계산해 매칭하고, 입양 후 재유기를 줄이는 것을 목표로 하는 유기동물 입양 플랫폼입니다.

- 라이프스타일-동물 적합도 매칭
- 소외 동물 공정 노출
- 입양 전 체감 미리보기 (AR)

## 📁 폴더 구조

```
src/
├── apis/          # Axios 인스턴스와 API 함수
├── assets/        # 이미지·아이콘 등 정적 리소스
├── components/    # 공용 UI 컴포넌트
├── constants/     # 상수 정의
├── hooks/         # 커스텀 훅
├── mocks/         # MSW 핸들러
├── pages/         # 라우트 단위 페이지
├── routes/        # 라우팅 설정
├── styles/        # 디자인 토큰 및 전역 스타일
├── types/         # 공용 타입 정의
└── utils/         # 유틸 함수
```
